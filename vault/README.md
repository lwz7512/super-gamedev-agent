# Studio vault

What this studio's games built and learned, offered to every game made from
this template. Read and written through `bash .claude/scripts/vault.sh` and the
`/studio-vault` skill; see `.claude/docs/studio-vault.md`.

- `modules/<engine>/<name>/`: reusable systems (`module.json`, `files/`, `tests/`, README, changelog)
- `lessons/`: what happened, the evidence, what to do next time
- `addenda/<skill>.md`: promoted lessons, read beside a library skill
- `games.json`: games made with `bin/new-game.sh`

Commit after harvesting, pushing or adding lessons: the vault's history is git's.
